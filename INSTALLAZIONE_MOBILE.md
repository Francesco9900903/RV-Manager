# Installazione mobile

## iPhone e iPad
1. Aprire RV Manager Enterprise in Safari.
2. Toccare Condividi.
3. Selezionare "Aggiungi alla schermata Home".
4. Confermare il nome.

## Android
1. Aprire RV Manager Enterprise in Chrome.
2. Aprire il menu del browser.
3. Selezionare "Aggiungi a schermata Home" o "Installa app".

## Limiti attuali
RV Manager resta una web app ospitata su Streamlit Cloud.
Non offre ancora funzionamento offline, notifiche push native o
timbratura senza connessione.
