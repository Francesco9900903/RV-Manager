# Checklist prima della produzione

- [ ] Tutte le chiavi esposte sono state rigenerate.
- [ ] La secret/service role key non è presente nel repository.
- [ ] I bucket documentali sono privati.
- [ ] Le tabelle sensibili hanno RLS attiva.
- [ ] Un dipendente non vede i dati di un altro.
- [ ] Il manager può eseguire le funzioni amministrative.
- [ ] Il Registro eventi registra le operazioni principali.
- [ ] È stato creato un backup JSON.
- [ ] È stato eseguito il backup dei PDF.
- [ ] La versione stabile è stata taggata su GitHub.
- [ ] L'app è stata testata da desktop e smartphone.
