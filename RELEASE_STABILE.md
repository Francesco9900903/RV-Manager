# Creazione release stabile

1. Verificare che l'app funzioni su desktop e smartphone.
2. Eseguire la checklist Sicurezza e collaudo.
3. Creare un backup JSON.
4. Eseguire il backup dei bucket PDF.
5. Su GitHub creare il tag `v3.5.0-stable`.
6. Creare una Release associata al tag.
7. Conservare una copia ZIP del repository.
